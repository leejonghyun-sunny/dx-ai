## 2. 핵심 계산 로직 (역공학 완료)

엑셀 원본을 분석하여 도출한 CAPA 계산 공식이다. 파이썬 구현 시 이 로직을 그대로 재현해야 한다.

```
SPH          = (3600 ÷ ST) × 가동율
필요시간      = 계획수량 ÷ SPH
생산가능M.hr  = 월근무시간 × 인원
과부족(시간)  = 생산가능M.hr - 필요시간
과부족(인원)  = 과부족(시간) ÷ 월근무시간
과부족(수량)  = 과부족(시간) × SPH
과부족(일수)  = 과부족(시간) ÷ 일근무시간
```

**용어 정의**

| 기호 | 의미 |
|------|------|
| ST | Standard Time — 1개 생산에 걸리는 표준 시간 (초/EA) |
| SPH | Shots Per Hour — 시간당 생산 가능 수량 |
| 가동율 | 설비 실제 가동 비율 (%) |
| M.hr | Man-Hour (인시) |

## 6. 디버깅 전략 (확정)

안전한 실무 배포를 위한 4대 안전망이다.

### 6.1 병행 운영 (Phase 1~4 전 구간)
파이썬 자동화와 기존 엑셀을 동시에 운영한다. 결과 불일치 시 엑셀 기준을 우선 적용한다.

### 6.2 중간값 전체 로그 기록
SPH, 필요시간, 생산가능M.hr 등 모든 중간 계산값을 로그 파일에 기록한다. 어느 단계에서 오류가 발생했는지 즉시 추적 가능한 구조를 유지한다.

```python
import logging

logging.basicConfig(
    filename="capa_debug.log",
    level=logging.DEBUG,
    format="%(asctime)s [%(levelname)s] %(message)s"
)

# 중간값 로깅 예시
logging.debug(f"SPH 계산: (3600 / {st}) × {가동율} = {sph:.4f}")
logging.debug(f"필요시간: {계획수량} ÷ {sph:.4f} = {필요시간:.4f}")
```

### 6.3 이상 데이터 즉시 경고
ST=0, 음수 계획수량 등 비정상 입력값을 조용히 넘기지 않고 명시적으로 출력·중단한다.

```python
def validate_inputs(st, 계획수량, 가동율):
    if st <= 0:
        raise ValueError(f"[경고] ST 값 이상: {st} — 0 이하 입력 불가")
    if 계획수량 < 0:
        raise ValueError(f"[경고] 계획수량 음수: {계획수량}")
    if not (0 < 가동율 <= 1.0):
        raise ValueError(f"[경고] 가동율 범위 초과: {가동율}")
```

### 6.4 TDD — 허용 오차 ±0.01%
파이썬 계산 결과와 엑셀 원본 결과를 자동 비교한다. 허용 오차는 ±0.01%로 설정한다.

```python
def assert_capa_result(py_result, excel_result, tolerance=0.0001):
    diff = abs(py_result - excel_result) / excel_result
    assert diff <= tolerance, (
        f"검증 실패: 파이썬={py_result:.4f}, 엑셀={excel_result:.4f}, "
        f"오차={diff*100:.4f}%"
    )
```

### 6.5 월초 승인 게이트
첫 실행 결과를 이사님께 보고 후 확정하는 승인 절차를 유지한다. 자동화가 완성되더라도 월초 1회는 반드시 사람이 검토한다.
